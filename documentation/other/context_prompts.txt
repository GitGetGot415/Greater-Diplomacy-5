MAINTENANCE PREFERENCES
======================

These notes restate the original maintenance requests.
AGENTS.md defines the repository rules that apply to changes.

Code ownership
--------------

Use constants.py for values shared across modules.
Use queries.py for shared questions about current game state.
Check existing helpers before you add another function.
Combine duplicate functions, calculations, and variables when their behavior is equivalent.
Make similar systems use the same rules unless gameplay requires a difference.
Remove unused functions and organize imports when those changes are in scope.

Preserve behavior and explanations
----------------------------------

Preserve intentional comments. Update a comment when the code makes it inaccurate.
Do not change gameplay during cleanup unless you fix an obvious bug or the user requests the change.
Check settings defaults, saves, and loads after related changes.

Caching and AI text
------------------

Use caches instead of repeated disk reads where appropriate.
Put rule-based AI response text in the AI response library.
Read it through ai_prompts rather than embedding it in behavior code.

Attributes
----------

Use direct attributes for required state.
Unnecessary getattr fallbacks can hide renamed fields or incomplete initialization.
Keep fallbacks only where compatibility or optional state requires them.

Layout
------

Keep screen layout values in the screen that uses them.
Group those values near the top of the file.
Use one shared value for repeated spacing or placement.
Do not move local layout values into constants.py.

Tests and handoff
-----------------

Test useful behavior and layout conditions.
Avoid tests that only fix an arbitrary button coordinate.
Give a small example when it helps explain a change.
Show the relevant changes instead of entire files or a generic change log.

Documentation
-------------

Keep documentation as simple as possible without losing accurate information.
Use ASD-STE100 Simplified Technical English as required by AGENTS.md.
