Greater Diplomacy 4 AI response reference
==========================================

Source: TEMP_GD4/project.json, target 'AI Message Processor'.
The normal processor compared Type and Status. Status maps to the GD5
strength names as follows: We are Weak = weaker; Roughly Equal = even;
We are Strong = stronger. A line was selected randomly from the eligible
Example Responses pool.

The GD4 export also contains a separate uncalled stack labelled
'Really Really long responses'. It is included at the end and marked as
uncalled so every preserved response is accounted for without claiming it
was reachable through the broadcast handler.
