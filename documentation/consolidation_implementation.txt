CONSOLIDATION IMPLEMENTATION NOTES
================================

Scope
-----

The attached consolidation plan defines five ownership changes.
This implementation does not reorganize the rest of data/queries.py or change content tuning.
The initial working tree was clean. No commits were created.
The referenced documentation/consolidation_audit.md was absent from this checkout.

Orders callbacks recheck live units. Tactical control remains restricted to the selected division.
AI authority comes from internal call sites. Client payloads cannot supply authority or payment-settlement flags.
Local batch eligibility and selection order remain with Orders.
Batch repairs retain aggregate affordability. Mixed aircraft mission groups skip unsupported choices as before.
Unchanged paid orders retain their host-owned countdown and reserved payment.
Complete drafts settle cancellation refunds before combined production and repair payment.
Current drafts also enforce subject control and faction authority before actions can be sent.
Self-targeted leave and disband requests retain their documented command targets.
Domain state still applies in cargo, unit, queue, diplomacy, and volunteer-reservation order.

Library refresh does not replace another world's active dictionaries.
The old global-scenario setter remains a compatibility export. Active world loading does not call it.
Diplomacy snapshots distinguish country mappings, so read-only passes cannot reuse another world's answers.

Mode checks
-----------

Single-player and hotseat use shared unit services with their current controlling identity.
Tactical actions use the selected division and its existing payment account.
Local spectator and editor setup effects retain their explicit existing permissions and immediate effects.
Scripts use shared availability and existing privileged setup functions.
Tournament imports retain review, replacement, stale-file checks, and duplicate checks.
Real-time clients submit choices. The server validates and applies them.
History retains independent country and faction snapshots.
GD4 and GDHex translations still enter normal world loading.
No tutorial interaction or asset changes are planned.
