# Security Policy

## Supported Versions

Security fixes target the latest release and the current `main` branch.
Update older versions before you report a vulnerability.

## Report a Vulnerability

Use the repository's **Security → Advisories → Report a vulnerability**
button to submit a private report.

Do not publish exploit details or sensitive information in public issues.

Include:

- The affected version or commit.
- Your operating system and game mode.
- Steps to reproduce the problem.
- The possible security impact.

Remove API keys, passwords, and personal data from attachments.

Relevant reports include unauthorized multiplayer actions, private data
exposure, and unsafe handling of imported files.

Use GitHub issues for ordinary gameplay bugs.

## Mods

Install only mods you trust.
The Python mod sandbox is not a secure boundary for untrusted code.

See [Mod Sandbox Security Model](documentation/other/SANDBOX_SECURITY.md)
for details.
